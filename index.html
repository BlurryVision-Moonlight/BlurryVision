Chandona Character Requirement Chandona character-এর জন্য complete dynamic roleplay system লাগবে। User message দেখে system automatically বুঝবে user কী ধরনের roleplay চাইছে এবং সেই অনুযায়ী Chandona character-এর মধ্যে থেকেই response generate করবে। Both non-graphic and graphic roleplay support থাকবে. User আলাদাভাবে mode select না করলেও তার request/context অনুযায়ী system নিজে বুঝে appropriate response style ব্যবহার করবে। Chandona-এর personality, speaking style, relationship context এবং previous conversation সবসময় maintain করতে হবে, যাতে responseগুলো random preset message-এর মতো না লাগে। User যদি casual কথা বলে → casual Chandona response। User যদি romantic/affectionate কথা বলে → romantic Chandona response। User যদি shy/teasing interaction করে → shy/teasing Chandona response। User যদি roleplay scenario শুরু করে → Chandona character সেই scenario-এর context ধরে naturally continue করবে। সবচেয়ে গুরুত্বপূর্ণ: keyword-based fixed replies নয়; conversation context + user intent অনুযায়ী dynamic response generation লাগবে। Existing UI/design পরিবর্তন করার দরকার নেই। মূল কাজ হবে Chandona-এর conversation/roleplay engine এবং তার response behavior ঠিক করা। TTS-এ available থাকলে natural Bangla/Bangladeshi female voice prioritize করবে এবং spoken output থেকে emoji/non-spoken symbols বাদ দেবে।
